Sanal Portföy

Panelde görünen hisselerle, gerçek para kullanmadan al-sat denemesi yapabileceğin bir simülatör. Portföy verisi bu reponun içindeki portfolio.json dosyasında tutulur — bu yüzden hangi tarayıcı/cihazdan girersen gir aynı portföyü görürsün. Görüntülemek için bir şey gerekmez; al-sat yapmak için aşağıdan bu tarayıcıya bir GitHub erişim anahtarı tanımlaman gerekir.

Al-sat işlemleri, portföyü bu repoya kaydedebilmek için bir GitHub erişim anahtarı (fine-grained personal access token) gerektirir. Anahtarı yalnızca bu repo için, sadece "Contents: Read and write" izniyle oluştur ve sadece bu tarayıcıda saklanır (repoya gönderilmez, sadece GitHub API isteklerinde kullanılır). Adımlar README'de.
